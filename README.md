# Basit Ahmed Portfolio Website

A modern, multi-page portfolio website for Basit Ahmed - Brand-Focused Graphic Designer & Video Editor.

## 🚀 Project Structure

```
Basit-Portfolio/
├── index.html                 # Home/Landing page
├── .env                       # Environment configuration
├── README.md                  # Project documentation
├── LICENSE                    # License file
├── basit portfolio.html       # Original single-page version (backup)
├── index.old.html            # Previous index backup
│
├── assets/
│   ├── css/
│   │   └── style.css         # Custom styles
│   ├── js/
│   │   └── main.js           # JavaScript functionality
│   └── images/               # Image assets
│
└── pages/
    ├── about.html            # About page
    ├── services.html         # Services page
    ├── portfolio.html        # Portfolio with filters
    ├── experience.html       # Employment & Certifications
    └── contact.html          # Contact form & info
```

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **Tailwind CSS**: Utility-first CSS framework
- **Vanilla JavaScript**: Pure JS, no dependencies
- **Google Fonts**: Inter font family

## 🚀 Getting Started

1. Open `index.html` in your browser
2. Or use a local server (Laragon, XAMPP, Live Server)
3. Update `.env` with your information
4. Add your images to `assets/images/`

### Using Laragon

```bash
http://localhost/Basit-Portfolio
```
